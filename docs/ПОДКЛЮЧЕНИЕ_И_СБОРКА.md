# Подключение, pinout и сборка опытного образца

Автономная система предупреждения о малой высоте БПЛА (сигнальная).
Вариант B: радар Acconeer XM125 (основной) + лидар Benewake TFmini-S (сравнение/резерв).

> Назначение: оповещение пилота/автопилота о снижении ниже заданной высоты H_ср (2…10 м).
> Выходы — только сигнальные (зуммер, LED, дискретный флаг, CAN-телеметрия).
> Инициирующих/исполнительных цепей нет.

---

## 1. Состав макета

| Модуль | Роль | Питание | Интерфейс |
|---|---|---|---|
| Acconeer XM125 | измерение высоты (основной) | +3,3 В | UART |
| Benewake TFmini-S | измерение высоты (сравнение) | +5 В | UART |
| STM32 Nucleo-G474RE | обработка, порог, интерфейсы | +5 В (отладка) | — |
| TJA1051 (модуль) | связь с СУ БПЛА | +5 В / +3,3 В | CAN |
| D24V5F3 | +5 → +3,3 В | +5 В | — |
| Зуммер + LED | оповещение | +5 / +3,3 В | GPIO |

Питание макета при отладке — от USB Nucleo. В полёте — от BEC БПЛА (+5 В) через D24V5F3.

---

## 2. Pinout и соединения

### 2.1. Радар Acconeer XM125 → MCU (USART1)

| XM125 | STM32G474 | Примечание |
|---|---|---|
| VCC | +3,3 В | 3,3 В |
| GND | GND | общий |
| TX (out) | PA10 (USART1_RX) | данные радара |
| RX (in) | PA9 (USART1_TX) | команды |

### 2.2. Лидар Benewake TFmini-S → MCU (USART2)

| TFmini-S | STM32G474 | Примечание |
|---|---|---|
| 5V | +5 В | питание лидара |
| GND | GND | общий |
| TX (out) | PA3 (USART2_RX) | данные лидара |
| RX (in) | PA2 (USART2_TX) | команды (режим, порог) |

> Уровни UART у TFmini-S — 3,3 В (вход 5 В-tolerant по питанию). Прямое подключение к STM32 допустимо.

### 2.3. Связь с СУ БПЛА (CAN)

| TJA1051 | STM32G474 / шина | Примечание |
|---|---|---|
| TXD | PA12 (CAN_TX) | |
| RXD | PA11 (CAN_RX) | |
| VCC | +5 В | |
| GND | GND | |
| CANH | CANH БПЛА | витая пара |
| CANL | CANL БПЛА | витая пара |

Терминатор 120 Ом — на концах шины (один может быть на модуле).

### 2.4. Оповещение и дискретный выход

| Сигнал | STM32G474 | Схема |
|---|---|---|
| Зуммер | PB0 | PB0 → затвор 2N7002; зуммер между +5 В и стоком; диод 1N4148 параллельно зуммеру |
| LED | PB1 | PB1 → R 1 кОм → LED → GND |
| «LOW ALT» | PB2 | PB2 → оптопара/транзистор с открытым стоком → разъём X2 |

## 3. Порядок сборки макета

1. **Питание.** Подать +5 В на Nucleo (USB). Собрать D24V5F3, проверить +3,3 В мультиметром.
2. **Радар.** Подключить XM125 (через XC120) к +3,3 В и USART1. Проверить поток данных терминалом.
3. **Лидар.** Подключить TFmini-S к +5 В и USART2. Проверить поток данных.
4. **Оповещение.** Собрать узел зуммера (Q1 + диод) и LED (R + LED), подключить к PB0/PB1.
5. **CAN.** Подключить TJA1051 к PA11/PA12, +5 В, терминатор 120 Ом.
6. **Дискретный выход.** Собрать оптопару/открытый сток на PB2, вывести на X2.
7. **Проверка.** Прогнать прошивку (см. отдельный раздел), проверить срабатывание на 2, 5, 10 м.

---

## 4. Проверка работоспособности

| Тест | Метод | Критерий |
|---|---|---|
| Измерение высоты | эталонная рулетка/лазерный дальномер | расхождение ≤ 0,1 м (лидар), ≤ 0,3 м (радар) |
| Срабатывание порога | задать H_ср = 2, 5, 10 м | флаг «LOW ALT» + зуммер при H ≤ H_ср |
| Перестройка порога | команда по CAN от СУ | порог меняется, подтверждение в телеметрии |
| Задержка | лог времени (таймер MCU) | ≤ 1 мс от отсчёта до флага |
| Потеря связи | отключить CAN | сохраняется последний порог, работа продолжается |
| Питание | 4,5…5,5 В | стабильная работа |

---

## 5. Меры по стойкости к перегрузкам (10g / 3g)

- Заливка модулей и разъёмов компаундом (полиуретан) — защита паяных выводов.
- Крепление 4×M2 к корпусу, корпус — к раме БПЛА через виброразвязку.
- Разъёмы — с фиксацией (JST-GH с защёлкой).
- Проверка на вибростенде (5…20 g RMS, до 2 кГц) перед лётными испытаниями.
