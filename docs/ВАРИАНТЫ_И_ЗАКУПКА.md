# Варианты исполнения и закупка в российских магазинах

Автономная система предупреждения о малой высоте БПЛА (сигнальная).
Документ содержит 4 варианта исполнения и закупочные списки с ссылками на
российские магазины.

> **О ссылках.** Поиск в интернете в момент подготовки был недоступен, поэтому
> ссылки даны **на поиск по партномеру** в магазине (они стабильны и не «протухают»).
> Наличие, цену и срок поставки подтверждайте на странице поиска при заказе.
> Цены — ориентировочные, в рублях на дату подготовки, без учёта доставки.

> **Назначение — только сигнализация.** Выходы: зуммер, LED, дискретный флаг,
> телеметрия. Исполнительных/инициирующих цепей нет.

## 8. Рекомендации по закупке

1. **ЭКБ (MCU, трансивер, пассив, TVS):** ChipDip / Промэлектроника / Терраэлектроника / Элитан / Платан / Компэл — сравните цену и наличие по ссылкам.
2. **Модули датчиков (TFmini-S, TF-Luna, XM125):** Ozon / AliExpress (магазин Benewake) — быстрее и дешевле; для XM125 — Mouser/Digi-Key.
3. **Корпус, разъёмы, зуммер:** Ozon.
4. **Отечественные аналоги** (если требуется импортозамещение): диод КД522 вместо 1N4148, транзистор 2П304 вместо 2N7002, светодиод АЛ307БМ; отечественный MCU/трансивер — уточнить по перечню ЭКБ предприятия.
5. **Демпфер/защита:** обязательно TVS + предохранитель по питанию от BEC.

## 9. Что уточнить перед заказом

- Берём ли за основу единый датчик A121 (рекомендуется — единственный по ТЗ)?
- Требуется ли **импортозамещение ЭКБ** (только отечественные компоненты)?
- Есть ли предпочтения по интерфейсу: CAN или UART к СУ БПЛА?
