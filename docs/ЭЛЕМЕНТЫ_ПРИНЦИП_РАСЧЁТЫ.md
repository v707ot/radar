# Элементы, принцип работы, расчёты и схема работы

Автономный датчик оповещения о малой высоте БПЛА (сигнальный).
Документ отвечает на три вопроса: **из чего состоит**, **как работает и почему
выполняет ТЗ** (с расчётами), **как выглядит схема работы**.

> Назначение — только **сигнализация**. Выходы: зуммер, LED, дискретный флаг,
> CAN-телеметрия. Исполнительных/инициирующих цепей нет.

## 2. Принцип работы

### 2.1. Общий принцип

1. Датчики (6× A121) непрерывно измеряют **дистанции** до поверхностей по кругу.
2. MCU фильтрует отсчёты (медиана → при необходимости Калман).
3. Сравнивает высоту с порогом `H_ср`, заданным по CAN (2…10 м).
4. При `h ≤ H_ср` формирует **сигнал**: зуммер, LED, дискретный флаг, CAN-сообщение.
5. При пропадании данных дольше таймаута → **Fail-Safe** (аварийный флаг).

### 2.2. Принцип измерения — импульсный когерентный радар (PCR, 60 ГГц)

Дальность вычисляется по задержке отражённого импульса туда-обратно:

```
t = 2·h / c        →        h = c·t / 2
```

где `c = 3·10⁸ м/с`. Для нашей высоты:

| Высота h | Задержка t = 2h/c |
|---|---|
| 2 м | 13,3 нс |
| 10 м | 66,7 нс |

Задержка — наносекунды; A121 измеряет её корреляционной обработкой
последовательности импульсов (PCR) и отдаёт сырые данные по SPI.

**Поле зрения (пятно).** Без линзы A121 — полусферический источник (FoV ~120°).
Для канала «вниз» ставится диэлектрическая линза — она сужает луч, и диаметр
пятна на земле `D = 2·h·tg(FoV/2)`:

| h | FoV 30° | FoV 60° |
|---|---|---|
| 2 м | 1,07 м | 2,31 м |
| 10 м | 5,36 м | 11,5 м |

С линзой FoV ≈ 30° пятно на 10 м ≈ 5 м — этого достаточно для усреднения по
рельефу и сохранения погрешности ≤ 1 м.

**Безопасность:** 60 ГГц, мощность излучения — десятки мВт; соответствует
нормам ISM-диапазона, безопасен для людей.

### 2.3. Разрешение по дальности и точность

Разрешение по дальности PCR-радара определяется шириной полосы:

```
ΔR = c / (2·B)
```

| Радар | Полоса B | Разрешение ΔR |
|---|---|---|
| 24 ГГц (NRA24) | ~250 МГц | 0,60 м |
| 60 ГГц (A121) | ~1,5 ГГц | **0,10 м** |

У A121 шаг дискретной шкалы — **≈2,5 мм**, что с запасом покрывает требование
погрешности ≤ 1 м. Точность ограничена не датчиком, а рельефом и наклоном
(см. раздел 3.3).

### 2.4. Алгоритм обработки

1. **Приём** кадра (SPI, сырые данные от A121).
2. **Валидация**: контрольная сумма, диапазон, сигнал (strength).
3. **Медиана** по 3 отсчётам — отсекает выбросы.
4. **Фильтр Калмана** (опция) — сглаживает шум и даёт вертикальную скорость `v`.
5. **Сравнение с порогом** с гистерезисом ΔH = 0,3 м (защита от «дребезга»).
6. **Предиктивное упреждение** (компенсация задержки): срабатывание, если
   `h + v·T_задержки ≤ H_ср`.
7. **Выдача** сигналов (зуммер, LED, флаг, CAN).

## 3. Расчёты по требованиям ТЗ

### 3.1. Требование 1: H_сраб = 2…10 м с варьированием

- **Диапазон уставки:** 2,0…10,0 м.
- **Шаг:** 0,1 м → 81 значение (при шаге шкалы A121 ≈2,5 мм запас огромный).
- **Кодирование по CAN:** `uint16` в миллиметрах (2000…10000), запас точности 1 мм.
- **Диапазон датчика** должен покрывать уставку с запасом:
  `L_max ≥ H_ср_max + запас`. Для A121 `L_max = 12 м > 10 м` ✅.
- **Хранение уставки:** в EEPROM/флеш MCU, сохраняется при отключении питания.

### 3.2. Требование 2: тип датчика (помехозащищённый, см/мм или лазер)

- **Принят радар 60 ГГц (A121)** — мм-диапазон, всепогодный, помехозащищён,
  работает сквозь пыль, дождь, туман; не зависит от освещённости и грунта.
- **Лидар 905 нм** (TFmini-S) — точно и дёшево, но зависит от погоды и **не
  проходит** по реакции ≤ 1 мс.
- **Ультразвук и CW-доплер — не применять** (см. `СРАВНЕНИЕ_ДАТЧИКОВ_CN.md`, раздел 0).

### 3.3. Требование 3: погрешность ≤ 1 м

**Важно:** итоговая погрешность определяется **всеми** источниками, а не только
ошибкой датчика. Ниже учтены все четыре составляющие.

Бюджет погрешностей (сумма квадратов — независимые источники):

```
ε = √(ε_датчика² + ε_наклона² + ε_динамики² + ε_цели²)
```

| Составляющая | Значение | Примечание |
|---|---|---|
| ε_датчика (A121) | ±0,05 м | шаг шкалы ≈2,5 мм + шум ⚠️ |
| ε_наклона (α = 5°) | 0,04 м | `h·(1/cos α − 1)`, h = 10 м |
| ε_наклона (α = 10°) | 0,15 м | без компенсации по IMU |
| ε_динамики | 0,03 м | **снижение 3 м/с × задержка ~0,5 мс (A121)** |
| ε_цели (трава, склон, вода) | 0,05…0,30 м | зависит от рельефа и материала |
| ε_шума (С/Ш) | 0,02 м | для радара A121 на 10 м |

**Расчёт по вариантам (сумма квадратов всех составляющих):**

| Условия | Расчёт | ε, м | ≤ 1 м? |
|---|---|---|---|
| Наклон 5°, ровная твёрдая земля, зависание | √(0,05²+0,04²+0,02²) | **0,07** | ✅ |
| Наклон 5°, ровная земля, снижение 3 м/с | √(0,05²+0,04²+0,03²+0,02²) | **0,07** | ✅ |
| Наклон 10°, трава/склон, снижение 3 м/с | √(0,05²+0,15²+0,03²+0,30²) | **0,34** | ✅ |
| Наклон 10°, вода (зеркальное отражение) | — | **отказ** | ❌ |

**Ключевые выводы (исправление):**

1. **ε_динамики у A121 мала** (0,03 м): при снижении 3 м/с и задержке ~0,5 мс
   высота «уходит» всего на 3 см — реакция ≤ 1 мс резко снижает этот вклад.
2. **ε_цели — доминирующий источник** на пересечённой местности (до 0,30 м):
   трава, кусты, наклонный склон дают ложную высоту.
3. **Вода/зеркальная поверхность** — не «погрешность», а **отказ измерения**
   (луч не возвращается). Требование формально не нарушено, но прибор не работает.
4. **Наихудший реалистичный случай (0,34 м)** — требование ≤1 м выполняется
   с запасом ~2,9×.

> **Компенсация** (улучшает бюджет): учёт наклона по IMU (`h = L·cos θ`) и
> динамическое упреждение (`h + v·T`) убирают ε_наклона и ε_динамики.

> ⚠️ **Что подтвердить.** Для гарантии ≤1 м на реальной местности нужен натурный
> пролёт над травой/склоном — расчёт даёт оценку, но ε_цели зависит от рельефа.

### 3.4. Требование 4: время реакции ≤ 1 мс (ФИЗИЧЕСКАЯ реакция)

**Уточнено заказчиком:** нормируется **физическая** реакция — от фактического
изменения высоты до начала звука. Это самое жёсткое требование ТЗ.

```
T_реакции = T_кадра + T_передачи + T_обработки + T_выдачи ≤ 1 мс
```

| Составляющая | Формула / значение | Примечание |
|---|---|---|
| T_кадра (датчик) | режим HSM: накладные расходы кадра **≈36 мкс** | см. ниже |
| T_передачи | SPI, 20…50 МГц, 16…32 бит | ~1…3 мкс |
| T_обработки | разбор + медиана + сравнение | ~10…20 мкс |
| T_выдачи | переключение выхода | ~5 мкс |

**Почему A121 проходит.** В режиме высокой скорости (HSM) фиксированные
накладные расходы кадра у A121 составляют всего **C_f ≈ 36 мкс**; один кадр —
это десятки микросекунд, то есть частота кадров **≥ 2 кГц**. Сырые данные
снимаются по SPI (без «коробочной» фильтрации и UART-задержек), поэтому полная
реакция укладывается в **~0,2…0,5 мс**.

**Сравнение вариантов:**

| Вариант | f_обн | Интерфейс | T_реакции | ≤ 1 мс? |
|---|---|---|---|---|
| Лидар TFmini-S, номинал | 100 Гц | UART 115 200 | ~10,8 мс | ❌ |
| Лидар TFmini-S, макс | 1 000 Гц | UART 921 600 | ~1,12 мс | ❌ **не проходит** |
| ToF-матрица VL53L5CX | 15 Гц | I²C | ~67 мс | ❌ |
| Радар 24 ГГц NRA24 | 20…100 Гц | UART/CAN | 10…50 мс | ❌ |
| **Радар 60 ГГц A121 (HSM)** | **≥2 кГц** | **SPI** | **~0,2…0,5 мс** | ✅ **проходит** |

**Вывод:** при **физической** трактовке ни лидар TFmini-S (1,12 мс), ни
ToF-матрица VL53L5CX (15 Гц) не проходят. Требование обеспечивает **только
радар A121** — за счёт съёма сырых данных по SPI и режима HSM. Поэтому A121
принят **единым датчиком** для всех каналов, а кольцо ToF исключено.

> ⚠️ **Что подтвердить.** Значение C_f ≈ 36 мкс — из документации Acconeer
> (режим HSM). Нужно **измерить натурно** время от изменения высоты до звука
> на собранном образце.

### 3.5. Требование 5: масса ≤ 100 г

> ⚠️ **Ключевое уточнение.** Расчёт ниже — **без аккумулятора**, при питании от
> бортовой сети БПЛА. Если «автономный» означает **работу без борта** (со своим
> питанием), масса вырастет — см. раздел 3.5а.

| Позиция | Масса, г |
|---|---|
| 6× радар A121 (модули XM125) | 18 |
| MCU STM32G474 | 1 |
| PCB 4 слоя 45×40 мм | 12 |
| CAN-трансивер + обвязка | 2 |
| DC-DC + защита | 3 |
| Зуммер | 3 |
| LED + резисторы | 2 |
| Разъёмы | 4 |
| Крепёж | 3 |
| Корпус IP54 + компаунд | 35 |
| **Итого (без батареи)** | **83** |

Запас до 100 г: **17 г (17 %)**.

> Для сравнения: с радаром NRA24 (~50 г) даже один канал даёт ~115 г — **лимит
> нарушен**. A121 (~3 г/шт) — единственный вариант, укладывающийся в массу.

### 3.5а. Автономность: масса с аккумулятором (задано 3 ч)

**Уточнено заказчиком:** автономность = **3 часа**. Считаем батарею при
**среднем** потреблении ≈ 0,55 Вт (см. 3.8 — канал «вниз» опрашивается постоянно,
кольцо — с пониженной частотой, A121 в паузах в SLEEP):

```
E = P·t / η = 0,55 Вт · 3 ч / 0,85 ≈ 1,94 Вт·ч
```

При LiPo 1S (3,7 В) нужна ёмкость:

```
C = E / U = 1,94 / 3,7 ≈ 525 мА·ч
```

С запасом 30 % на деградацию и холод: **C ≈ 700 мА·ч**.

| Батарея | Ёмкость | Масса | Ресурс | Итого масса | ≤ 100 г? |
|---|---|---|---|---|---|
| **LiPo 1S 700 мА·ч** | 2,59 Вт·ч | **~14 г** | **3,5 ч** | **~97 г** | ✅ **рекомендуется** |
| LiPo 1S 800 мА·ч | 2,96 Вт·ч | ~16 г | 4,0 ч | ~99 г | ⚠️ впритык |
| LiPo 1S 1000 мА·ч | 3,70 Вт·ч | ~20 г | 5,0 ч | ~103 г | ❌ превышает |
| LiPo 2S 700 мА·ч | 5,18 Вт·ч | ~30 г | 7,0 ч | ~113 г | ❌ превышает |

**Вывод:** для 3 ч автономности достаточно **LiPo 1S ~700 мА·ч (≈14 г)**;
масса изделия ≈ **97 г ≤ 100 г** ✅ (запас 3 г).

> ⚠️ **На холоде ёмкость LiPo падает на 20…30 %.** При −20 °C расчётные 3 ч
> превращаются в ~2,1…2,4 ч. Для гарантии — батарея с запасом (но тогда масса
> уходит за 100 г) либо подогрев. Это уточнить при испытаниях.

### 3.6. Требование 6: температурный диапазон −20…+40 °C

| Компонент | Рабочий диапазон | Проходит? |
|---|---|---|
| Радар A121 | −40…+85 °C | ✅ |
| STM32G474 | −40…+85 °C | ✅ |
| TJA1051 | −40…+150 °C | ✅ |
| DC-DC MP1584 | −40…+85 °C | ✅ |
| Зуммер | −20…+60 °C | ✅ |

**Вывод:** требование −20…+40 °C выполняется с запасом по всем компонентам
(A121: −40…+85 °C). Уязвим только аккумулятор LiPo — при −20 °C ёмкость падает;
рекомендуется батарея с запасом или подогрев.

### 3.7. Требование 7: перегрузка 10g осевая / 3g радиальная

**Сила, действующая на элементы** `F = m·a` (a = 10g = 98,1 м/с²):

| Элемент | Масса | Сила при 10g |
|---|---|---|
| 6× радар A121 | 18 г | 1,77 Н |
| Корпус | 35 г | 3,43 Н |

**Проверка крепления.** Крепёж M2 (4 винта) на срез: допустимая нагрузка ~50 Н
на винт → запас > 40× ✅.

**Резонанс.** Собственная частота подвеса датчика:
```
f_н = (1/2π)·√(k/m)
```
При жёстком креплении `k ≈ 10⁶ Н/м`, `m = 0,011 кг`:
`f_н = (1/2π)·√(10⁶/0,011) ≈ 1 500 Гц`.

Частота винтов БПЛА 100…200 Гц → коэффициент расстройки `r = 0,07…0,13`,
коэффициент передачи `1/(1−r²) ≈ 1,01` — **резонансного усиления нет** ✅.

**Требования к конструкции:**
- жёсткое крепление датчика (без консольных выступов);
- естественная частота сборки ≥ 2 кГц;
- заливка тяжёлых элементов компаундом;
- фиксация разъёмов (вибростойкие JST-GH с защёлкой).

### 3.8. Энергопотребление (конфигурация с кольцом 360°)

| Потребитель | Напряжение | Ток | Мощность |
|---|---|---|---|
| 6× радар A121 (поочерёдный опрос, 3,3 В) | 3,3 В | ~60 мА ср. | 0,198 Вт |
| STM32G474 | 3,3 В | 40 мА | 0,132 Вт |
| CAN-трансивер | 5 В | 10 мА | 0,050 Вт |
| Зуммер (импульсно) | 5 В | ~10 мА ср. | 0,050 Вт |
| Потери DC-DC (~15 %) | — | — | 0,065 Вт |
| **Итого (все каналы активно)** | | | **≈ 0,80 Вт** |

> **Режим энергосбережения.** A121 в состоянии SLEEP потребляет всего **3 мА**.
> Канал «вниз» опрашивается постоянно (реакция ≤ 1 мс), а кольцо — с пониженной

> ≈ **0,55 Вт**, что и заложено в расчёт батареи (раздел 3.5а).

## 4. Схема работы

### 4.1. Алгоритм (конечный автомат)

См. `hardware/work_algorithm.svg`. Состояния:

| Состояние | Действие | Переход |
|---|---|---|
| **INIT** | инициализация SPI, CAN, таймеров | → SELF-TEST |
| **SELF-TEST** | проверка 6× A121 и связи | ок → CONFIG, ошибка → FAIL-SAFE |
| **CONFIG** | приём уставки H_ср по CAN | → MEASURE |
| **MEASURE** | SPI-кадр A121 + фильтр (медиана/Калман) | → DECISION |
| **DECISION** | `h ≤ H_ср + v·T`? | да → WARNING, нет → NORMAL |
| **NORMAL** | LED зелёный, флаг = 0, телеметрия | → MEASURE |
| **WARNING** | зуммер + LED красный, флаг = 1, CAN | гистерезис → NORMAL |
| **FAIL-SAFE** | аварийный флаг, LED мигает | при восстановлении → CONFIG |

### 4.2. Временная диаграмма реакции

См. `hardware/timing_diagram.svg`. Моменты времени:

| Метка | Событие |
|---|---|
| t₀ | высота пересекла H_ср |
| t₁ | завершено очередное измерение датчика |
| t₂ | кадр принят MCU (после SPI) |
| t₃ | порог сравнён, флаг сформирован |
| t₄ | выход активен (зуммер/LED/CAN) |

### 4.3. Взаимодействие с СУ БПЛА (последовательность)

```
СУ БПЛА ──CAN──▶ [уставка H_ср] ──▶ Датчик
Датчик  ──CAN──▶ [высота, флаг, статус] ──▶ СУ БПЛА
Датчик  ──GPIO─▶ [флаг LOW ALT, открытый сток] ──▶ полётный контроллер
Датчик  ──локально──▶ зуммер + LED (пилот слышит/видит)
```

## 5. Сводка выполнения требований ТЗ

| № | Требование | Решение | Статус |
|---|---|---|---|
| 1 | H_сраб 2…10 м, варьирование | уставка по CAN, шаг 0,1 м, хранение в EEPROM | ✅ |
| 2 | Радар (см/мм) или лазер | радар 60 ГГц A121 (6 шт) | ✅ |
| 3 | Погрешность ≤ 1 м | ε = 0,07…0,34 м с учётом **всех** источников | ✅ при наклоне ≤ 10° |
| 4 | Реакция ≤ 1 мс (**физическая**) | **A121 (SPI, HSM)** проходит; TFmini-S и VL53L5CX — нет | ✅ |
| 5 | Масса ≤ 100 г | 97 г с батареей 700 мА·ч | ✅ (запас 3 г) |
| 6 | −20…+40 °C | A121 (−40…+85 °C); батарея теряет ёмкость на холоде | ✅ запас батареи |
| 7 | 10g осевая / 3g радиальная | F ≤ 3,4 Н, запас крепежа >40×, резонанс не возбуждается | ✅ |
| 8 | **Обзор 360° (земля, стены, потолок)** | кольцо 4× A121 + 1 вверх + 1 вниз | ✅ стены до 12 м |

**Открытые пункты:**
1. **№4 — реакция.** Выполнимо только на A121 (SPI, HSM). Нужно **натурное
   измерение** времени от изменения высоты до звука на собранном образце.
2. **№5 — масса.** Запас всего 3 г: требует аккуратного подбора батареи и
   энергосбережения (поочерёдный опрос каналов). Следить при компоновке.
3. **№6 — холод.** Батарея LiPo на −20 °C теряет 20…30 % ёмкости → 3 ч не
   гарантируются. Нужна батарея с запасом или подогрев.
