# Ссылки: даташиты и закупка в России

Справочник по компонентам устройства: официальные технические описания
(datasheet) производителей и прямые ссылки на закупку в российских магазинах.

> **Назначение — только сигнализация.** Все компоненты ниже относятся к
> сигнальному устройству (зуммер, светодиод, дискретный флаг, CAN-телеметрия).
> Инициирующих/исполнительных цепей в изделии нет.

> **Дата проверки ссылок: 18.11.2026.** Ссылки на даташиты проверены по ответу
> сервера (HTTP 200 / тип `application/pdf`). Ссылки на ChipDip — это прямые
> адреса товарных карточек вида `chipdip.ru/product/...`, полученные из
> публичного веб-архива (Wayback Machine), т.к. сайт ChipDip закрыт
> антибот-защитой (DDoS-Guard, HTTP 403 для автоматического доступа).

---

## 0. Как получить ссылки ChipDip (обход антибота)

Сайт `chipdip.ru` защищён JS-челленджем **DDoS-Guard** — автоматический запрос
получает `HTTP 403` и заглушку `DDoS-Guard`. Поисковики (Google, Яндекс, Bing,
DuckDuckGo) для этого домена также не отдают результаты автоматическому клиенту.
Рабочий способ — **публичный веб-архив Wayback Machine** (CDX API), который
хранит проиндексированные товарные страницы:

```
http://web.archive.org/cdx/search/cdx?url=chipdip.ru/product/<партномер>*\
&output=json&fl=original&collapse=urlkey&limit=20&filter=statuscode:200
```

Пример: запрос по `tja1051` возвращает реальные адреса
`/product/tja1051t-118-nxp`, `/product/tja1051t-cm-118` и т.д.
Всё, что начинается с `https://www.chipdip.ru/product/...` — прямая ссылка на
карточку товара (открывается в браузере без проблем; блокируется только
автоматический доступ).

**Практический вывод:** ссылки ChipDip ниже открываются в обычном браузере.
Если позиция снята с производства, карточка архива покажет её историческое
описание — на сайте нужно нажать «Поиск по каталогу» и уточнить актуальный аналог.
