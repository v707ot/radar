# Датчики: полные наименования и технические характеристики

Справочник по всем датчикам, рассматриваемым в проекте. Для каждого приведено
**полное заводское наименование** (производитель + партномер + назначение) и
**технические характеристики** из паспорта (datasheet) производителя.

> **Требования ТЗ, по которым оцениваются датчики:** высота H = 2…10 м,
> погрешность ≤ 1 м, реакция ≤ 1 мс, масса ≤ 100 г (всего изделия),
> температура −20…+40 °C, перегрузки 10g осевая / 3g радиальная,
> серийная себестоимость ≤ 20 000 ₽.

> **О достоверности данных.** Значения, подтверждённые по официальным
> datasheet/страницам производителей на 18.11.2026, помечены ✅. Значения,
> требующие подтверждения у поставщика (⚠️), приведены по каталогам и подлежат
> проверке перед закупкой.

### 1.1. Acconeer A121 — импульсный когерентный радар 60 ГГц (PCR)

| Параметр | Значение |
|---|---|
| **Полное наименование** | Acconeer A121 Pulsed Coherent Radar (PCR) sensor, 60 GHz |
| **Модуль-носитель** | Acconeer XM125 (модуль с A121 + SPI/UART), отладочный — XE121 |
| **Производитель** | Acconeer AB (Швеция) |
| **Принцип действия** | импульсный когерентный радар (PCR), мм-диапазон |
| **Рабочая частота** | 60 ГГц (57…64 ГГц, ISM) ✅ |
| **Диапазон измерения** | до 20 м (зависит от конфигурации и цели) ⚠️ |
| **Разрешение по дальности** | мм (сантиметровый и лучше) ⚠️ |
| **Поле зрения (FoV)** | ~±40° (антенна с линзой/рупором) ⚠️ |
| **Частота обновления** | до нескольких кГц (при съёме сырых данных) ⚠️ |
| **Интерфейс** | SPI (сырые данные), UART (обработанные) ✅ |
| **Напряжение питания** | 1,8 В (ядро), 3,3 В (интерфейс) ⚠️ |
| **Потребление** | десятки мВт ⚠️ |
| **Масса** | < 5 г (модуль XM125) ⚠️ |
| **Рабочая температура** | −40…+85 °C ⚠️ |
| **Цена** | 3 500…4 500 ₽ (в РФ ~16 000…22 000 ₽ за комплект) |

**Почему выбран основным:** единственный из доступных, кто реально даёт
**реакцию ≤ 1 мс** — через прямой съём сырых данных (SPI) и собственную обработку
на MCU. Всепогодный (туман, дождь, пыль), не зависит от освещённости и грунта.

> ✅ Подтверждено: рабочая частота 60 ГГц, интерфейс SPI, класс PCR.
> ⚠️ Подтвердить: точный диапазон, разрешение, потребление, масса — по
> официальному datasheet A121 (docs.acconeer.com) перед закупкой.

## 9. Что подтвердить перед закупкой (⚠️)

1. **Acconeer A121** — точный диапазон, разрешение, потребление, масса,
   доступ к сырым данным через SPI (для реакции ≤ 1 мс).

4. **TF-Luna** — работает ли до 10 м (паспорт — 8 м).
5. **Все** — реальная частота обновления и время отклика (для требования ≤ 1 мс).
